# Uitgangspunt: collega's kennen alleen chat-AI

Collega's hebben geen ervaring met agentische tools; het dichtstbijzijnde is een ChatGPT-prompt. Daarom start de cursus bij het verschil tussen chat en agent (bestanden lezen, commando's uitvoeren) en bij de permission prompt, voordat MCP of skills aan bod komen.

**Implications**: ASZ-afspraken (geen databaseverbinding, alleen geaggregeerde niet-herleidbare resultaten delen, eigen fine-grained GitHub-token) komen in elke les terug, zodat ze bij beginners blijven hangen.
