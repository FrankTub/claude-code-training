Begrippenlijst

Eén woord, één betekenis. Alle lessen gebruiken deze termen.

TermBetekenis
AgentAI die zelf acties uitvoert (bestanden lezen, commando's draaien, bestanden wijzigen), in plaats van alleen tekst terug te geven.
ContextAlles wat Claude in een sessie ziet: jouw berichten, gelezen bestanden, uitvoer van commando's. Raakt vol; /clear maakt hem leeg.
Permission promptVraag om toestemming voordat Claude een actie uitvoert. Keuzes: Yes, Yes don't ask again, No.
Permission modeInstelling die bepaalt welke acties zonder permission prompt mogen: Plan, Manual, Accept edits, Auto.
Prompt injectionVerborgen instructies in tekst van buiten (webpagina, issue, document) die Claude proberen te sturen.
ProjectmapDe map waarin je Claude Code start. Claude leest daar zonder te vragen.
SurfaceDe plek waar je Claude Code gebruikt: terminal (CLI), VS Code, of de desktop-app (Code-tab).
MCPModel Context Protocol. Standaard om Claude te koppelen aan externe systemen, zoals GitHub.
MCP-serverEen koppeling via MCP. Geeft Claude extra tools, bijvoorbeeld “issue lezen” of “pull request maken”.
SkillMap met een SKILL.md: vaste instructies voor een terugkerende taak. Aanroepen met /skill-naam, of Claude laadt hem zelf als de beschrijving past.
CLAUDE.mdBestand met projectregels dat Claude aan het begin van elke sessie leest.
Token (GitHub)Wachtwoord-achtige sleutel waarmee de GitHub MCP-server namens jou werkt. Geef minimale rechten.
