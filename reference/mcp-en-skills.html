GitHub MCP in vier stappen

  1. Fine-grained token op github.com/settings/personal-access-tokens: owner ASZ, einddatum, Only select repositories, Read and write op Actions, Contents, Issues, Pull requests.
  2. Token in 1Password; via $PROFILE als $env:GITHUB_PAT alleen tijdens claude.
  3. claude mcp add-json github '{"type":"http","url":"https://api.githubcopilot.com/mcp/","headers":{"Authorization":"Bearer ${GITHUB_PAT}"}}' -s user
  4. /mcp in Claude: connected = goed, failed + 401 = token fout.
