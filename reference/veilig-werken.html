Spiekbrief: veilig werken met Claude Code

Bij Les 1 · Bronnen: Security, Permission modes, Data usage

Zes regels

  1. Geen databaseverbinding. Claude schrijft de query, jij voert hem uit. Resultaten alleen geaggregeerd terugplakken, nooit herleidbaar naar een patiënt.
  2. Geen patiëntdata. Niet in prompts, niet in de map waar je Claude start. Verzonnen waarden gebruiken.
  3. Start in een projectmap. Nooit in je home-map of een netwerkschijf. Claude leest zonder vragen alles in de startmap.
  4. Lees voor je “Yes” kiest. Past de actie bij je vraag? Zo niet: No + toelichting.
  5. Wantrouw inhoud van buiten. Webpagina's, issues en documenten kunnen verborgen instructies bevatten (prompt injection).
  6. Geen /feedback bij gevoelige sessies. Het stuurt het gesprek, inclusief code, naar Anthropic; het wordt 5 jaar bewaard.

curl, wget, Invoke-WebRequest (internet) · rm, Remove-Item, DROP, DELETE (verwijderen) · git push (publiceren) · paden buiten je projectmap.

Gevoelige bestanden blokkeren

In .claude/settings.json van het project:

{
  "permissions": {
    "deny": ["Read(./.env)", "Read(./secrets/**)"]
  }
}

Deny-regels gelden in elke mode. Een .claudeignore-bestand doet niets. (Permissions)

Wat gebeurt er met je data?

Zakelijk account (Team/Enterprise): geen training op je prompts en code; standaard 30 dagen bewaard bij Anthropic. Lokaal: gesprekken 30 dagen in ~/.claude/projects/, als platte tekst. (Data usage)
