Voor de docent

Draaiboek: workshop Claude Code (60 min)

Gemengde groep. Lessen dienen als hand-out; deelnemers doen de oefeningen in de les.

Vooraf

  • Deelnemers hebben Claude Code geïnstalleerd (terminal of VS Code) of de desktop-app (niet-technisch).
  • Data engineers en BI hebben vooraf een fine-grained GitHub-token gemaakt (les 2, stap 1). Dat scheelt 5 minuten.
  • Jij: repo schoon op een nieuwe branch, query-vraag voor de demo klaar, databasetool open, GitHub MCP connected.
  • Stuur de map claude-code-training of de drie lessen vooraf rond.

Tijdschema

TijdWatWie
0–5Waarom: chat versus agent. Toon één permission prompt live.Jij
5–20Les 1: ASZ-afspraken, modes, oefening in de oefenmap.Iedereen
20–32Les 2: GitHub MCP. Engineers en BI doen mee; niet-technisch kijkt mee.Technisch
32–50Les 3: skills installeren, jouw demo van vraag tot pull request, daarna /grilling zelf.Jij, dan iedereen
50–57Quizzen van de drie lessen, samen bespreken.Iedereen
57–60Waar stel je vragen na vandaag? Spiekbrieven delen.Jij

Tijdens de demo hardop benoemen

  • “Nu vraagt Claude toestemming. Wat staat er precies? Past dit bij mijn vraag?”
  • “Ik voer de query zelf uit. Claude heeft geen databaseverbinding.”
  • “Dit resultaat is geaggregeerd en niet herleidbaar. Daarom mag het terug in de chat.”
  • “Een pull request maken is publiceren. Daar kies ik nooit ‘don't ask again’.”

Als het misgaat

  • /mcp toont failed: token verlopen, verkeerde repo gekozen, of GITHUB_PAT niet gezet. Controleer met claude mcp get github.
  • Skill niet gevonden: claude plugin marketplace add mattpocock/skills overgeslagen, of Claude niet herstart na installatie.
  • Tijd tekort: laat de oefening van les 3 als huiswerk.
