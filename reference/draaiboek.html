Voor de docent

Draaiboek: workshop Claude Code (60 min)

Gemengde groep. Lessen dienen als hand-out; deelnemers doen de oefeningen in de les.

Vooraf

  • Deelnemers hebben Claude Code geïnstalleerd (terminal of VS Code) of de desktop-app (niet-technisch).
  • Data engineers en BI hebben vooraf een fine-grained GitHub-token gemaakt (les 5, stap 1). Dat scheelt 5 minuten.
  • Jij: repo schoon op een nieuwe branch, query-vraag voor de demo klaar, databasetool open, GitHub MCP connected. De demo in les 4 maakt al een pull request via GitHub MCP; deelnemers koppelen het zelf pas in les 5.
  • Stuur de map claude-code-training of de vijf lessen vooraf rond.

Tijdschema

TijdWatWie
0–3Waarom: chat versus agent. Toon één permission prompt live.Jij
3–13Les 1: ASZ-afspraken, modes, oefening in de oefenmap.Iedereen
13–21Les 2: het context window. Jij toont /context vóór en na het lezen van een groot bestand, en daarna /clear. Deelnemers doen de oefening in de oefenmap.Jij, dan iedereen
21–29Les 3: AGENTS.md en CONTEXT.md. Jij toont /init en de tabel “welk bestand leest Claude”. Deelnemers doen stap 1–2 van de oefening; de rest is huiswerk.Jij, dan iedereen
29–43Les 4: skills installeren, jouw demo van vraag tot pull request, daarna /grilling zelf.Jij, dan iedereen
43–53Les 5: GitHub MCP. Engineers en BI doen mee; niet-technisch kijkt mee.Technisch
53–58Eén quizvraag per les, samen bespreken. De rest van de quizzen is huiswerk.Iedereen
58–60Waar stel je vragen na vandaag? Spiekbrieven delen.Jij

Tijdens de demo hardop benoemen

  • “Nu vraagt Claude toestemming. Wat staat er precies? Past dit bij mijn vraag?”
  • “Ik voer de query zelf uit. Claude heeft geen databaseverbinding.”
  • “Dit resultaat is geaggregeerd en niet herleidbaar. Daarom mag het terug in de chat.”
  • “Een pull request maken is publiceren. Daar kies ik nooit ‘don't ask again’.”

Als het misgaat

  • /mcp toont failed: token verlopen, verkeerde repo gekozen, of GITHUB_PAT niet gezet. Controleer met claude mcp get github.
  • Skill niet gevonden: claude plugin marketplace add mattpocock/skills overgeslagen, of Claude niet herstart na installatie.
  • Tijd tekort: laat de oefeningen van les 3 en les 4 als huiswerk. Les 2 kan desnoods als demo zonder oefening.
