Skills: van vraag tot query

Een skill is een vaste werkwijze die je met één commando start. In deze les zie je drie skills een vraag omzetten in een query en een pull request.

Referentie: Spiekbrief MCP en skills · Begrippenlijst · Vorige les: AGENTS.md en CONTEXT.md

Na deze les kun je: skills installeren en vinden, een skill aanroepen, en /grilling gebruiken om je eigen vraag scherp te krijgen.

1. Wat is een skill?

Een skill is een map met een bestand SKILL.md: instructies voor een taak die steeds terugkomt. Je start een skill zelf met / en de naam. Claude kan een skill ook zelf laden als je vraag past bij de description bovenin SKILL.md. De rest van de skill laadt pas als hij gebruikt wordt. (Skills docs)

Skills komen vaak in een plugin: een pakket met skills, soms ook tools en hooks. Skills uit een plugin heten /plugin-naam:skill-naam. (Skills docs)

Een plugin is code van iemand anders. Skills kunnen commando's laten uitvoeren en tools vooraf goedkeuren. Installeer alleen plugins van bronnen die je vertrouwt, en kijk eerst wat erin staat.

2. Installeren (iedereen)

We gebruiken de skills van Matt Pocock. Voer uit in een terminal:

claude plugin marketplace add mattpocock/skills
claude plugin install mattpocock-skills@mattpocock

Start daarna claude en typ /skills. Je ziet nu onder andere mattpocock-skills:grilling, mattpocock-skills:code-review en mattpocock-skills:pr. Typ /grill en de autocomplete vult de rest aan.

Desktop-app: open de Code-tab, typ / in het invoerveld en zoek de skill in de lijst.

3. Demo: van vraag tot query (Frank, ± 10 min)

Kijk mee en let op twee dingen: wanneer stelt Claude vragen, en wanneer vraagt het toestemming?

Claude krijgt geen databaseverbinding. Claude schrijft de query; Frank voert hem zelf uit. Terug in de chat komt alleen een geaggregeerd resultaat dat niet naar een patiënt wijst.
  1. Vraag scherp krijgen. In Plan mode: /mattpocock-skills:grilling Ik wil per afdeling per maand het aantal opnames tellen. Claude stelt genummerde vragen, elk met een aanbevolen antwoord. Wat telt als opname? Welke periode? Welke afdelingen? Je antwoordt per nummer.
  2. Query laten schrijven. Als het antwoord duidelijk is, maakt Claude een plan. Frank keurt het goed; Claude schrijft de query naar een bestand in de repo. Let op de permission prompt voor het schrijven.
  3. Zelf uitvoeren. Frank draait de query in zijn eigen databasetool. Hij plakt alleen het geaggregeerde resultaat terug als Claude het moet controleren.
  4. Laten reviewen. /mattpocock-skills:code-review main. Twee subagents kijken in een frisse context: past de code bij de regels van de repo, en doet hij wat gevraagd is?
  5. Pull request maken. /mattpocock-skills:pr schrijft de beschrijving. Claude maakt de pull request via de GitHub MCP-server. Die koppel je zelf in les 5. Frank leest de prompt voor create_pull_request voordat hij “Yes” kiest.

Tip: een aantal van 1 of 2 in een kleine groep kan herleidbaar zijn naar een persoon. Twijfel je of een aggregaat herleidbaar is? Plak het dan niet.

4. Zelf doen (± 4 min)

Gelukt? Je hebt een skill gevonden, gestart en gebruikt om je vraag scherper te maken voordat er één regel SQL bestaat.

5. Toets jezelf

Eerst uit je hoofd, niet terug scrollen.

Vraag 1

Hoe start je zelf een skill?

Bijvoorbeeld /mattpocock-skills:grilling. Tekst na de naam gaat als argument mee.

Vraag 2

Claude laadt soms zelf een skill. Waarop baseert Claude die keuze?

Claude vergelijkt je vraag met de description. Daarom beschrijft een goede skill precies wanneer hij nodig is.

Vraag 3

Wie voert in de demo de query uit op de database?

ASZ-afspraak: geen databaseverbindingen voor Claude. Jij voert uit; alleen geaggregeerde, niet-herleidbare resultaten gaan terug.

Vraag 4

Wat doe je voordat je een plugin met skills installeert?

Een plugin kan commando's laten uitvoeren en tools vooraf goedkeuren. Behandel hem als software van een derde.
