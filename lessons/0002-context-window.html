Het context window: waarom Claude soms vergeet

Claude ziet alleen wat in zijn werkgeheugen past. Hoe voller dat geheugen, hoe slechter het antwoord. Wie dat begrijpt, krijgt betere resultaten.

Referentie: Begrippenlijst · Vorige les: Veilig werken

Na deze les kun je: uitleggen wat het context window is en wat erin zit, met /context zien hoe vol het is, en kiezen tussen doorwerken, /compact en /clear.

1. Wat is het context window?

Een taalmodel onthoudt niets tussen twee vragen. Bij elke beurt stuurt Claude Code het hele gesprek opnieuw naar het model. Dat pakket heet de context. Het context window is de maximale omvang ervan, gemeten in tokens: stukjes tekst van gemiddeld een paar letters. Bij de meeste modellen past er ongeveer 200.000 tokens in.

Wat niet in de context staat, bestaat voor Claude niet. Wat er wel in staat, beïnvloedt elk antwoord, ook als het er niet meer toe doet.

2. Wat zit erin?

WanneerWat
Vóór je eerste vraagSysteeminstructies van Claude Code, je CLAUDE.md of AGENTS.md, korte beschrijvingen van skills, namen van MCP-tools.
Tijdens het werkJouw berichten, Claudes antwoorden, elk bestand dat Claude leest, de uitvoer van elk commando.

Let op het verschil tussen wat jij ziet en wat Claude ziet. In je scherm staat één regel Read afspraken.csv. In de context staat het hele bestand. Eén zoektocht door een map met queries kan zo tienduizenden tokens kosten. (Docs: context window)

3. Waarom het je antwoord beïnvloedt

“LLM performance degrades as context fills.” Bij een volle context vergeet Claude eerdere instructies en maakt het meer fouten. (Best practices) Drie herkenbare patronen:

PatroonWat gebeurt erOplossing
Alles in één sessieJe begint met een query, vraagt tussendoor iets over Power BI, en gaat terug naar de query. Oude, losse informatie leidt Claude af./clear tussen taken die niets met elkaar te maken hebben.
Blijven corrigerenClaude doet het fout, jij corrigeert, het blijft fout. Alle mislukte pogingen staan nog in de context en sturen het volgende antwoord.Na twee mislukte correcties: /clear en een betere eerste prompt met wat je geleerd hebt.
Eindeloos zoeken“Zoek uit hoe dit werkt” zonder grens. Claude leest honderden bestanden en de context loopt vol.Maak de vraag klein: noem de map of het bestand.

Een schone sessie met een goede prompt wint bijna altijd van een lange sessie vol correcties. (Best practices)

4. Je gereedschap

CommandoWat het doetWanneer
/contextToont hoe vol de context is en waarmee.Als antwoorden slechter worden, of uit nieuwsgierigheid.
/clearMaakt de context leeg. Je instructiebestand laadt opnieuw.Bij een nieuwe taak. Gebruik het vaak.
/compactVervangt het gesprek door een samenvatting. Met een opdracht stuur je wat blijft: /compact Bewaar de definitie van een opname.Midden in één lange taak, als je de draad wilt houden.
/rewindTerug naar een eerder punt in het gesprek (zie les 1).Claude sloeg een verkeerde weg in.

Raakt de context bijna vol, dan vat Claude Code het gesprek zelf samen (auto-compact). Een samenvatting verliest details. Wacht daar dus niet op: kies zelf je moment. (Best practices)

Ook zonder Claude Code geldt dit. In een lange ChatGPT-chat vergeet het model net zo goed wat je bovenaan schreef. Begin daar ook een nieuw gesprek voor een nieuwe vraag.

Alles in de context gaat naar Anthropic (zie les 1). Laat Claude dus geen grote exports of logbestanden lezen “om te kijken wat erin staat”. Dat kost context, en het kan patiëntgegevens bevatten. Geef Claude alleen wat het voor de taak nodig heeft.

5. Zelf doen (± 4 min)

Werk in je oefenmap uit les 1. Vink elke stap af.

Desktop-app: typ de commando's in het invoerveld van de Code-tab.

Gelukt? Dan heb je gezien dat de context al gevuld is vóór je eerste vraag, dat elk gelezen bestand ruimte kost, en dat /clear echt alles wist.

6. Toets jezelf

Eerst uit je hoofd, niet terug scrollen.

Vraag 1

In je scherm staat alleen Read Opname.sql. Wat staat er in de context?

Claude ziet de hele inhoud. Jij ziet één regel. Elk gelezen bestand kost dus ruimte.

Vraag 2

Je hebt Claude drie keer gecorrigeerd op dezelfde query, en het blijft fout. Wat werkt meestal het best?

De mislukte pogingen staan in de context en sturen het volgende antwoord. Begin schoon, met wat je nu weet.

Vraag 3

Je zit midden in een lange taak en de context raakt vol. Je wilt de draad niet kwijt. Wat doe je?

/compact vat samen en houdt de kern. /clear wist alles; dat is voor een nieuwe taak.

Vraag 4

Een collega wil Claude een export van 50.000 regels uit het DWH laten lezen “om te zien wat erin staat”. Wat is het probleem?

Twee problemen tegelijk: de antwoorden worden slechter, en mogelijk gaan patiëntgegevens naar buiten. Geef Claude alleen wat nodig is, en nooit echte patiëntdata.
